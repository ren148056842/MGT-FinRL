# 协议变化与执行语义

- 原账户资金1,000,000，净收益reward×0.1、lookback252及四技术指标配置从两份主要消融notebook用AST读取，只保存原设置，不执行代码。主实验未通过数据门槛，未将合成fixture状态说成原研究状态。
- 原混合close的收益、奖励与协方差可能被预测污染。新账本市场通道独立；features_mgt仅传策略观测；真实协方差及基础指标必须由合格raw历史计算。具体冻结预测替换技术指标的来源/期限仍待核验，未擅自引入复杂预测表示。
- 原环境直接用新权重乘t→t+1收益；新定义t收盘后动作、t+1真实收盘执行，旧数量先承担价格变化。无open时不能声称真实次日开盘成交。若预测目标t+1收盘，该价格预测在实际t+1收盘成交时已经到期；不能把此前涨幅算成新买收益。Top3即使有available_at也需讨论这个期限错配。
- 组合自融资，初始全现金；求费用后NAV再设目标，先卖后买、按可用现金缩量，不允许融资。每侧佣金简化合计c，滑点s只在现金扣；卖出印花税分日期计。F0—F6预先固定，非券商报价；不建模最低佣金、盘口冲击和未知涨跌停。
- 无每证券规则不认定100股一律适用；可传verified lots与tradable mask，未知缺失不作停牌。仅合成fixture使用分数股。实际股票数量账本需要独立可执行价格与公司行动支持，不能把复权价当真实成交价又忽略拆股调整。
- 主比较reward采用net single-period return×0.1；没有财富奖励或reward网格稳健性实证。财富reward的尺度和终值倾向不同，不能宣称等价。
- 指标统一252年化、rf_annual=0默认、样本标准差ddof=1、含初始资本的正值MDD；初始观察不算一个日收益。
- 2024是原研究已经看过的固定历史评估期，不称未见测试。当前protocol为LOCKED_BLOCKED，没有批准2022/2023/2024分割；新增合格来源必须另建版本/复核协议，不能直接改锁文件悄悄恢复。
- bootstrap先逐seed重算AR/SR/MDD差再平均，相同日期的相同抽样索引用于全部seed和配对策略。主block10/B2000，5/20仅敏感性；区间条件于冻结预测和已训练策略，不是完整训练流水线或独立市场证据，不计算未中心化“p值”。
- 合成接口短跑参数仅测试API，不是研究超参数或正式预算；正式E1/E2训练没有开始，旧checkpoint不被复用。
